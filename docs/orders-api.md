# API-контракт сервиса заказов

Письменная договорённость о том, что принимает и что отвечает сервис заказов.
Любое изменение этого файла — только через PR.

---

## POST /orders — создать заказ

**Назначение:** создать новый заказ для существующего клиента.

### Тело запроса

```json
{
  "account_id": 1,
  "product": "Кружка",
  "quantity": 2
}
```

| Поле        | Тип    | Обязательное | Ограничения                  |
|-------------|--------|--------------|------------------------------|
| account_id  | int    | да           | > 0                          |
| product     | string | да           | длина 1–128 символов         |
| quantity    | int    | да           | ≥ 1                          |

### Успешный ответ — `201 Created`

```json
{
  "id": 42,
  "account_id": 1,
  "product": "Кружка",
  "quantity": 2,
  "created_at": "2026-11-26T12:34:56.789Z"
}
```

### Ошибки

| Код | Когда возникает |
|-----|-----------------|
| **422** | Нет обязательного поля **или** `quantity < 1` **или** `product` пустой / слишком длинный. В теле — указание проблемного поля. |
| **404** | Клиент с таким `account_id` не существует (сервис заказов сходил в сервис клиентов и получил 404). |
| **503** | Сервис клиентов не отвечает (таймаут или сетевая ошибка). |

## GET /orders/{id} — получить заказ по номеру

**Назначение:** вернуть один заказ по его идентификатору.

### Параметры пути

| Параметр | Тип | Описание          |
|----------|-----|-------------------|
| id       | int | Номер заказа (> 0) |

### Успешный ответ — `200 OK`

Тот же объект, что и при создании:

```json
{
  "id": 42,
  "account_id": 1,
  "product": "Кружка",
  "quantity": 2,
  "created_at": "2026-11-26T12:34:56.789Z"
}
```

### Ошибки

| Код | Когда возникает |
|-----|-----------------|
| **404** | Заказа с таким `id` нет. В `detail` должно быть понятное сообщение с номером, который искали (например: `"order 42 not found"`). |

## GET /orders?account_id= — список заказов клиента

**Назначение:** вернуть все заказы одного клиента (или пустой список).

### Query-параметры

| Параметр    | Тип | Обязательный | По умолчанию | Ограничения     |
|-------------|-----|--------------|--------------|-----------------|
| account_id  | int | да           | —            | > 0             |
| limit       | int | нет          | 50           | 1 ≤ limit ≤ 200 |
| offset      | int | нет          | 0            | ≥ 0             |

### Успешный ответ — `200 OK`

Всегда массив (даже если заказов нет):

```json
[
  {
    "id": 42,
    "account_id": 1,
    "product": "Кружка",
    "quantity": 2,
    "created_at": "2026-11-26T12:34:56.789Z"
  }
]
```

или `[]`, если у клиента заказов нет.

### Ошибки

| Код | Когда возникает |
|-----|-----------------|
| **422** | `account_id` отсутствует или ≤ 0, либо `limit`/`offset` вне допустимого диапазона. |

---

## Общие правила

- Все даты — в формате ISO 8601 с таймзоной (UTC).
- Все идентификаторы — положительные целые числа.
- Сервис **никогда** не создаёт заказ, если клиент не существует.
- Адрес сервиса клиентов и таймаут берутся из настроек (`accounts_url`, `accounts_timeout_seconds`), а не захардкожены.
